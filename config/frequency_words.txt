# 本次修正要点（基于对 445 条真实热榜标题的实测匹配分析）：
#   1. 【关键】修正 \b 单词边界失效
#      Python 的 \b 把汉字也算作单词字符，导致中英混排标题全部失配。
#      实测漏掉的典型标题：
#        "TES和IG瑞士轮对手实力如何"  "S16瑞士轮首日赛程"

#      既能贴合中文，又不会命中 AIDS/SAIC 这类词内片段。
#   2. 【关键】修正 ! 排除词的作用域
#      解析器把所有 ! 词收集成一张全局表，实际对所有词组生效，
#      与原注释"仅限当前词组"不符。会误杀无关领域的新闻。
#      改为把排除条件写进本组的正则（负向断言），作用域回到本组。
#   3. 补齐实测漏掉的高价值主体（对齐 ai_interests.txt 的 5 个关注方向）：

#   4. 修正"三星"误命中"三星堆"、"苹果"误命中水果类等噪音
